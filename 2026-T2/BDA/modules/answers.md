## Question 5 - exploring and cleaning
an observation x is flagged as an outlier if it falls outisde the range between lower and upper fences
Outlier iff x < (Q1 - 1.5 × IQR)  OR  x > (Q3 + 1.5 × IQR)

from most naive to most sophisticated we go:
1. fill with a global constant: replaces with unknown or 0
2. ignore the tuple: deletes the row
3. mean/median imputation: fills missing values with avg or middle value of that column
4. most-probable-value imputation: infer the most contextually accurate replacement value with the help of relationships across attributes (via predictive models like regression, decision trees, knn)

## Question 6 - Classification algorithms
1r: finds the best rule for 1 attribute, high cardinality ids overfit
nb: combines class probabilities, assumes conditional independence
dt: recursively split best attributes, grows too specific without pruning

information gain biases dt's towards features with many distinct values and gain ratio is a cure for that because it starts measure split information, which measures the potential information generated by splitting the training data into many partitions - it acts as a penalty for features with too many outcomes
