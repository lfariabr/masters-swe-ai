# Module 7 · Activity 2 - Organisation X: communicating a scope change before a pilot (draft)

Organisation X is piloting the integration of internal and external systems. Before any pilot starts, scope changes have to be found and agreed. Two people own that: an IT engineer and a project manager. Writing as both.

**Contextual considerations**

1. **Who loses what.** A scope change moves work, budget or a date. For each stakeholder, name which of the three it touches before the meeting, because that is the frame they will hear everything through (Cerri, 2000, step 3).
2. **Internal and external are different rooms.** An external vendor hears "scope change" as a contract question; an internal team hears it as a priority question. Same message, two registers.
3. **Evidence over opinion.** The engineer brings the technical reason (an interface that does not exist, a data field that is not populated). The project manager brings the cost of each option. Neither speaks without the other.
4. **Decisions need a record.** A change agreed in a corridor and not written down is a change that will be disputed at go-live.

**Communicating the strategy**

- **One page first.** Current scope, proposed change, three options with cost and date, recommendation. A picture of the integration with the changed part marked. That page goes to the sponsor before any meeting.
- **Match the audience.** Sponsor: options and a decision date. Vendor: contract clause and interface spec. Internal teams: what changes in their week.
- **Check it landed.** Every message ends with a question the receiver has to answer. Silence is not agreement (Cerri's step 5).
- **Then the register.** Agreed change, who approved it, when, and what it displaces. Published where every stakeholder can see it.

In my placement the version of this is a rules note the stakeholder signs before the build runs. It is the cheapest scope control I have used.

**Question for you:** as the engineer, how do you say "this cannot be done by that date" to a sponsor who has already announced the date?
